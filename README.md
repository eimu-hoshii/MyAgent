## 1. クイックスタート（Windows）

### ワンクリック起動（黒画面非表示）
- **`NIA_起動・再起動.vbs`**: バックエンドサーバー（`:8000`）および未起動時の **AivisSpeech エンジン（`:10101` 裏起動・二重起動防止付き）** をサイレント起動し、Web管制コンソールを開きます。
- **`NIA_マスコット常駐のみ起動.vbs`**: 裏サーバー＋Windowsネイティブ透過デスクトップマスコットのみを起動します。
- **`NIA_完全停止.vbs`**: 稼働中のサーバーおよび常駐マスコットを完全停止します。

### アクセス URL
| 画面 | URL | 用途 |
| :--- | :--- | :--- |
| **Web管制コンソール** | `http://127.0.0.1:8000/` | チャット・プリセット切替・自律運用・VTuber配信スタジオ・全8タブ統合設定 |
| **OBS透過オーバーレイ** | `http://127.0.0.1:8000/?mode=obs` | OBS「ブラウザソース」用（背景完全透過・バイリンガル字幕・各種配信カード対応） |
| **ブラウザ簡易マスコット** | `http://127.0.0.1:8000/?mode=mascot` | ブラウザ単体での縦長マスコット表示 |

## 2. 主要機能ハイライト

### 🚀 第2世代 コアアーキテクチャ（5大拡張）
1. **機能整理UI ＆ 1クリック スキルプリセットパック (`SKILL_PRESETS`)**
   - `🌱 シンプルUI ⇄ ⚙️ フル管制` トグルで画面情報密度を即座に切替。
   - 5種のプリセット（`☀️ 秘書・日課自動化` / `💻 開発・設計アーキテクト` / `📺 配信・雑談＆多言語` / `🎉 配信・企画フル演出` / `🪶 軽量ミニマル常駐`）でモード・モデル・ツール・UI密度を一括最適化。
2. **LLMハイブリッド自動ルーティング（速度⇄知能切替＋自己レビュー）**
   - 短文・挨拶は `fast`（`gemma4:e4b`）、標準ツール処理は `balanced`（`12b`）、設計・比較分析・コード相談は `smart`（`gemma4:26b` ＋ 1パス自己レビュー）へ自動ルーティング。VTuberモードでは安全な非検閲解除モデルへ自動制約。
3. **体感遅延半減：文単位Streaming先読みTTS ＋ 確定字幕表示**
   - `IncrementalJsonSpeechExtractor` により `tool_call: null` を安全確認しつつ 1文目から先読みTTS合成・連続再生。字幕は `speech_ready` で完成全文を1回確定表示するため途中でチラつかず安定。
4. **記憶の高度化（ローカル意味ベクトル検索 ＋ 夜間自動睡眠統合）**
   - `SudachiPy` 形態素見出し語＋概念同義語クラスタ＋2-gram による 256次元 L2正規化ベクトル検索（追加VRAMゼロ）。重複・高類似記憶を自動マージする `consolidate_memories()` を搭載。
5. **リアルタイム多言語翻訳 ＆ バイリンガル字幕 (`en` / `ko` / `zh`)**
   - 日本語発話と同時に第2言語翻訳字幕を `#subtitle-box`（OBS対応）とチャット欄へ併記。`（笑顔で）` 等のト書き括弧は表示・読み上げ前に自動除去。

### 🛡️ AIエージェント（戦術・常駐モード）全12拡張＋直接制御
- **自律ツール全17種**: 気象庁公式天気 (`get_weather`)、日付付きWeb検索 (`web_search`)、本文深掘り (`fetch_webpage`)、画面キャプチャ認識 (`vision_capture`)、PC診断 (`system_diagnostics`)、長期記憶 (`save_memory` / `search_memory`)、繰り返し予定 (`manage_task`)、許可アプリ起動 (`local_launch`)、ローカルファイル読み書き (`file_op`)、SQLite FTS5 ローカル資料検索 (`rag_search`)、HITL承認制コマンド実行 (`run_command`)、Playwright動的ブラウザ操作 (`browser_action`)、非同期並列調査 (`deep_research`)、外部連携 (`external_service`: GitHub / iCal / Gmail)、MCPクライアント (`mcp_tool`)、Windows環境・電源制御 (`windows_control`)。
- **空振りゼロの直接制御 ＆ 確定データ・ブリーフィング**:
  - **PCロック / スリープ / 音量制御**: マスターの直接指示（「PCをロックして」「PCスリープして」「音量上げて」）を確認バナーなしで100%先行実行し、返答送信完了直後にロック/スリープを発火。
  - **戦術ブリーフィング（定時 / 手動 / Discord `!briefing`）**: 気象庁天気・未完了タスク・PC状態・最新テックニュースをシステム側で確実に先行取得し、引用元データ付きで報告。
  - **AivisSpeech ワンクリック裏起動 (`🚀 Aivis裏起動`)**: 二重起動を防止しつつ、ウィンドウを出さずにバックグラウンドで AivisSpeech エンジンを起動・接続。
- **Discord Bot 双方向連携**: DM/チャンネル対話、スレッド別文脈分離、画像/音声/PDF/Office文書添付解析、VC接続TTS発話 (`!joinvc`)、コマンド承認ボタン連携。

### 📺 自律型VTuber（ライブ配信モード）全12拡張
- YouTube Live / Twitch チャット取得＆高速コメバッチ、OBS WebSocket v5 シーン自動切替、VTube Studio 感情パラメータ注入、ニュース引用オーバーレイカード、PII/ローカルパス出力ハードガード、ゲーム/動画の画面変化検知実況、視聴者参加型投票/クイズ/大喜利、相方コラボ2人掛け合いモード、匿名お便り箱、場面別シンセBGM（発話中オートダッキング）＆スパチャ祝祭エフェクト、歌枠 LRC 歌詞同期＆終了後MC、配信アーカイブ・YouTubeチャプター・X告知文自動生成。

## 3. セキュリティ・Git管理ポリシー
- APIキー・Discord Botトークン・OBSパスワード等の機密情報は `data/secrets.json` に分離保存され、`.gitignore` により Git 管理対象から厳格に除外されています。
- 個別設定 (`data/persona_settings.json`)、会話・記憶DB (`data/agent_memory.db`)、音声/画像キャッシュもすべてローカル専用として `.gitignore` で保護されています。
